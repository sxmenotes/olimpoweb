## Sobre el Proyecto

Olimpo Prop es una aplicación web actualmente en desarrollo. 

## Notas sobre el Repositorio

El repositorio de GitHub (al que se subirá este proyecto posteriormente) será utilizado principalmente para enlazar y gestionar el despliegue automático de la página a través de **Vercel**.

## 🚀 Notas de la Versión 0.1.1

### Arquitectura y Construcción
Esta aplicación web está construida con tecnologías estándar y no requiere de un proceso de compilación (build) complejo. 
Vercel desplegará automáticamente el sitio leyendo el archivo `index.html` en la raíz del proyecto.

### Estructura de Archivos
La estructura principal del proyecto está organizada de la siguiente manera:

```text
OLIMPO PROP/
├── index.html       # Archivo principal de la aplicación (Punto de entrada)
├── css/             # Hojas de estilo
│   └── style.css
├── js/              # Lógica de la aplicación y configuraciones
│   ├── main.js
│   └── tailwind-config.js
├── img/             # Recursos de imágenes
├── README.md        # Documentación del proyecto
└── LICENSE          # Licencia MIT
```
